# Contributing to Shabucks

Thank you for your interest in contributing to Shabucks! We welcome contributions from everyone.

## 🚀 Getting Started

1.  **Fork the repo** on GitHub.
2.  **Clone your fork** locally.
3.  **Install dependencies**:
    ```bash
    npm install
    ```
4.  **Create a branch** for your changes:
    ```bash
    git checkout -b feature/your-feature-name
    ```

## 🛠️ Development Workflow

1.  **Environment Setup**:
    - Copy `.env.example` to `.env`.
    - Fill in the required environment variables.
2.  **Run Development Server**:
    ```bash
    npm run dev:all
    ```
3.  **Linting**:
    ```bash
    npm run lint
    ```
4.  **Testing**:
    ```bash
    npm test
    ```

## 📜 Pull Request Guidelines

-   Keep your PRs focused. If you have multiple unrelated changes, create separate PRs.
-   Ensure all tests pass.
-   Follow the existing code style.
-   Write clear, descriptive commit messages.

## 🛡️ Security

If you discover a security vulnerability, please do NOT open an issue. Instead, report it privately to the maintainers.
