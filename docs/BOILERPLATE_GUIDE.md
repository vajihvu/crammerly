# Production-Grade Express Boilerplate (Crammerly Edition)

This project has been transformed into a production-grade monorepo. It follows industry best practices for security, observability, and scalability.

## 🏛️ Architecture Highlights

### 1. Robust Middleware Chain
The order in `backend/app.js` is critical for security:
1.  **Helmet**: Injects security headers first.
2.  **CORS**: Restricts domain access before processing data.
3.  **Rate Limiter**: Blocks DoS/Scrapers before body-parsing (saving CPU/RAM).
4.  **RequestId**: Attaches a `uuid` for cross-service tracing.
5.  **Observability**: Latency and status logging for every request.
6.  **Body Parsers**: Includes `depthLimit` to prevent malformed payload attacks.
7.  **Zod Validator**: Strict schema enforcement per route.
8.  **Error Handler**: Catch-all for formatting and log redaction.

### 2. Observability & Logging
*   **Winston Logger**: Structured JSON logging in production.
*   **Automatic Redaction**: Sensitive keys like `password` are scrubbed via a custom Winston format.
*   **Correlation IDs**: `X-Request-ID` is present in every log statement and response header.
*   **Audit Logging**: High-value events (logins, deletions) are recorded in the `AuditLog` collection.

### 3. Identity & Access Management
*   **Cookie-based Refresh**: Tokens stored in `httpOnly` secure cookies.
*   **Short-lived Access**: JWTs expire in 15 minutes.
*   **Rotation**: Refresh tokens rotate on use to detect/prevent replay attacks.
*   **IP Anomaly Detection**: Sessions are revoked if a new request comes from a different IP (configurable).

### 4. Data Layer Performance
*   **Lean Queries**: Using `.lean()` in controllers for faster read-only paths.
*   **Compound Indexes**: Multi-field indexes on `Records` and `Todos` for performant study feeds.
*   **Orphan Cleanups**: Background maintenance jobs to keep the database pruned.

## 📦 Key Directory Map
*   `/backend/config`: Zod-validated environment and application config.
*   `/backend/middleware`: Logic for security, auth, and observability.
*   `/backend/schemas`: Source of truth for API payload structures.
*   `/backend/utils`: Helpers for tokens, maintenance, and structured logging.
*   `/docs`: Security audits, threat models, and architectural specs.
